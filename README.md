# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

同一印张名在队列里互斥：已有待处理或领取中的同名时，再投同名会被门禁退回并点出冲突编号；已出结论的同名可再开新一笔。导航里的「重名门禁」是整页门禁台：上区冲突监视（是否拦截、冲突编号、解除条件），中区在途同名，下区历史已结论，底部是门禁流水。每次拦截与放行各记一条流水，可按印张名翻查。只读账号能看门禁台与两栏清单，但不能投递。

## 启动

```bash
cd projects/15-print-register-review
docker compose up --build
```

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/auth/login | 登录拿令牌 |
| GET | /api/jobs | 队列总表 |
| POST | /api/jobs | 送复核；同名在途返回 409 与冲突编号 |
| GET | /api/gate/status?sheet=名 | 门禁状态：冲突编号、解除条件、在途与已结论两栏 |
| GET | /api/gate/events?sheet=名 | 门禁流水，可按印张名翻 |

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 再送一条青偏差 0.5 的印张，状态先是待处理，随后变成套不准。
3. checker 没有送复核按钮。
4. printer 投「样张甲」进入待处理，马上再投同名被退回并点出冲突编号；「重名门禁」整页上区冲突监视显示拦截与冲突编号，中区在途同名有这一笔。
5. 等第一笔出结论后再投同名可以收下；门禁台下区历史已结论出现第一笔，中区在途清空。
6. 门禁流水里放行与拦截各有一条记录，可按印张名翻查；checker 能看门禁台与两栏清单，但不能投递。
